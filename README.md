Simulador de Llamadas con IA para Entrenamiento de Agentes (Telecomunicaciones)
Diseñé y desarrollé una plataforma web interactiva en tiempo real que simula llamadas de clientes de telecomunicaciones utilizando Inteligencia Artificial. El sistema genera escenarios dinámicos (Soporte Técnico y Facturación) mediante prompt engineering avanzado para entrenar y evaluar a agentes de servicio.

Arquitectura en tiempo real: Implementé comunicación bidireccional mediante WebSockets y FastAPI para procesar voz a texto (Web Speech API) y texto a voz (Edge-TTS) sin latencia perceptible.

Integración de LLM: Orquesté el modelo LLaMA 3.3 (vía Groq API) para interpretar respuestas en vivo, generando interacciones de clientes altamente realistas y adaptativas.

Auditoría automatizada (QA): Programé un sistema de evaluación automatizado que audita la transcripción completa de la llamada contra métricas de calidad reales del sector (apertura, empatía, sondeo y resolución), generando retroalimentación puntual para el agente.

🛠️ Tecnologías clave para destacar en las etiquetas/tags de tu portafolio:
Backend: Python, FastAPI, WebSockets.

Frontend: JavaScript (Vanilla), HTML5, CSS3, Web Speech API.

IA & APIs: Groq API (LLaMA 3.3-70b), Prompt Engineering, Edge-TTS.
